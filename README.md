# Runtime Magazine - Mini CMS

This project is a dynamic magazine website with a custom mini-CMS, built with React, Vite, TypeScript, and Tailwind CSS.

## Project Structure

The entire application code is located in the `runtime-magazine/` directory.

## How to Run

1.  **Navigate to the project directory:**
    ```bash
    cd runtime-magazine
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

The application will be available at `http://localhost:5173`.

## Features

*   **Public Site:** A fully dynamic website that displays articles and categories.
*   **Admin Panel:** A comprehensive admin panel at `/admin` for managing content.
    *   CRUD operations for articles, categories, and authors.
*   **Custom Styling:** A unique "geeky" and "underground" theme.
